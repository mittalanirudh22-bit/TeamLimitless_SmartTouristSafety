# Data sources
- Microsoft GeoLife GPS Trajectory Dataset: https://www.microsoft.com/en-my/download/details.aspx?id=52367
- Geofabrik/OpenStreetMap: https://download.geofabrik.de/asia/india.html
- Government tourism data: https://data.gov.in/catalog/india-tourism-statistics
- NCRB/OGD crime data: https://www.data.gov.in/catalog/crime-india-2023
- MP State Crime Records Bureau: https://scrb.mppolice.gov.in/crime_in_mp.php

Public GeoLife does not provide synchronized real emergency labels. Demo SOS/incident scenarios should therefore be clearly marked as controlled/synthetic. Keep sensitive tourist data off public blockchains.
